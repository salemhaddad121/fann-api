Fann API Reference

Complete endpoint documentation for the Fann platform — connecting artists with bookers across Lebanon.

Version v1
Base URL https://api.fann.app/v1
Protocol HTTPS only
Format application/json

Authentication

All protected endpoints require a Bearer token in the Authorization header:

Authorization: Bearer <jwt_token>

Tokens are issued by POST /auth/otp/verify, POST /auth/login, POST /auth/google, and POST /auth/apple. Tokens expire after 7 days. Admin endpoints additionally require role: "admin" in the token payload.

  • public — No token required
  • auth — Valid JWT required
  • admin — Admin JWT required

Response — 201 Created

}
Errors
Code
Meaning
400
Validation failed — fields object lists all failing fields at once
409
Email already registered
503
Account created but SMS delivery failed — prompt user to resend OTP
Note: Registration does not return a token. Navigate to OTP entry immediately, passing user_id to POST /auth/otp/verify. Return all validation errors simultaneously — never one at a time.
